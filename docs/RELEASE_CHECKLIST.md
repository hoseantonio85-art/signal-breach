# QA / Release Checklist — RuStore v1

## Веб (перед слиянием UX-правок)
- [ ] `npm install && npm run build` без ошибок
- [ ] Тап по ячейке: действие только после подъёма пальца
- [ ] Долгое удержание: до отпускания флаг не выставлен; на отпускании выставлен ровно один
- [ ] Долгое удержание + свайп: ни открытие, ни флаг не срабатывает
- [ ] `pointercancel`: нет действия
- [ ] Короткий тап в режиме «карантин»: ровно один флаг при отпускании
- [ ] Правая кнопка мыши: флаг только на отпускании; контекстное меню не открывается
- [ ] Левая кнопка мыши: одно раскрытие при отпускании
- [ ] Перезапуск / домой / звук: действие на отпускании; иконки видны; подписи доступны screen reader
- [ ] Клавиатура: Tab/Enter/Space работают
- [ ] Скролл больших карт 16×30 и 16×18 без случайного нажатия

## Android QA
- [ ] Установка / запуск на Android 13+ и на более узком экране
- [ ] Нет полос/зазоров и конфликтов с системными жестами и вырезами
- [ ] Игра работает без интернета
- [ ] Интеракции не срабатывают преждевременно / дважды
- [ ] Вибрация/звук/пауза работают ожидаемо
- [ ] Подтверждение выхода, кнопка Back
- [ ] Сохранение текущей партии после убийства процесса
- [ ] Сюжет: пройти тестовые операции 1, 5, 10
- [ ] Free Run: TRACE, BREACH, BLACK ICE
- [ ] Мины и карантин корректны на просмотре карты

## Release
- [ ] Иконка, скриншоты и тексты карточки
- [ ] Декларация данных и privacy policy по фактическому поведению
- [ ] VersionCode больше опубликованного, versionName отражает версию
- [ ] Release APK подписан правильным ключом
- [ ] Ключ и пароли надёжно сохранены вне GitHub
- [ ] APK загружен в RuStore, пройдена модерация
- [ ] Ссылка на релиз и дата публикации внесены в документацию
