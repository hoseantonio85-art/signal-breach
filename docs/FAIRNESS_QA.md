# SIGNAL//BREACH — аудит логической решаемости (только QA)

Скрипт `scripts/analyze-board-solvability.mjs` использует **настоящий** `createBoard/generateBoard/reveal/toggleQuarantine` проекта и псевдослучайный генератор с фиксированными seed **только для тестирования**. Production-генератор, количество мин, UX, скорость и сложность игры НЕ меняются.

Методика: 100 одинаково воспроизводимых полей для каждого OP 06–10 при первом ходе из центра и из угла (всего 1000). Решатель использует только видимые цифры и отмеченные флаги: базовое правило «все / ни одной»; вычитание уравнений вложенных соседств; общее число оставшихся мин. Реальные минные координаты **никогда не используются для выбора хода**, только для автоматического контроля честности дедукций.

**Критически важно:** `stalled` означает «решатель с ограниченным набором логических правил не смог продолжить», а **не** математическое доказательство, что игрок *обязан* угадывать. Существуют более сильные методы: общая система ограничений, перебор согласованных комбинаций / компоненты границы, связи между раздельными группами через общий бюджет мин. Статистику не трактовать как долю «нечестных» карт.

Порядок: сначала оценить базовые результаты, затем при необходимости написать полноценный CSP решатель и лишь после этого решать менять ли `generateBoard`, защищать ли кампанию от 50/50 или добавлять подсказки/сканер.

Результат: CI Actions `Gameplay fairness QA (test only)`, `qa-reports/fairness-op06-10.json` в artifact. Пример seed записан в JSON для повторения конкретной доски. Отдельная ветка `qa/op07-10-solvability`. Никакого merge в игровые/релизные ветки.
