## Не входит в v1
Синхронизация сохранений, аккаунты, таблицы лидеров, покупки, реклама, push, сервер и новый сюжет.

## Правила готовности
- `npm run build` проходит;
- APK стартует без сети и не запрашивает лишних разрешений;
- однозначное действие на отпускании без двойных срабатываний;
- прогресс и активная партия переживают закрытие;
- поведение на маленьком Android-экране проверено;
- веб-версия не регрессировала.
