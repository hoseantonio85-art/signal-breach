# SIGNAL//BREACH — документация проекта

Статус: подготовка первого Android-релиза для RuStore. Дата начала: 2026-10-31.

## Источники истины
- **GitHub `main`** — утверждённая исходная версия игры и источник GitHub Pages.
- **GitHub `feature/release-interactions-icons`** — изолированные правки управления и трёх иконок; сливать только после проверки.
- **GitHub `release/android-rustore-v1`** — планируемая ветка Android-адаптации от утверждённой версии `main`; Android-специфичные изменения не должны ломать Pages.
- **TickTick / SIGNAL//BREACH · Android / RuStore** — личный список действий, не техническая спецификация.
- **Google Drive** — использовать позже только для внешних материалов: скриншоты магазина, экспортированные графические файлы, тексты публикации и документы, которые не должны жить в коде. Не дублировать Markdown без необходимости.

## Процесс работы
1. Изменение требований → дополнить соответствующий документ и при необходимости задачу.
2. Разработка в отдельной ветке → PR с описанием и проверками.
3. Проверить браузерную версию и, после появления Android-сборки, APK на устройстве.
4. Только после проверки объединять изменения с `main`.
5. Перед RuStore заморозить версию, собрать релиз, зафиксировать версию и подписать APK.

## Состояние на 2026-10-31
- React + TypeScript + Vite, 10 сюжетных операций, 3 сложности Free Run, RU/EN, звук.
- Прогресс кампании хранится локально; текущая незавершённая партия не восстанавливается.
- Нативной Android-сборки в репозитории пока нет.
- Веб-деплой: `.github/workflows/pages.yml`, запускается push в `main`.
- Первая UX-правка: все действия на release, а не press-down; длительное нажатие только распознаёт намерение, выставляет флаг при отпускании.
- Вторая UX-правка: заменить аудио, перезапуск и переход домой на иконки из библиотеки Lucide.
