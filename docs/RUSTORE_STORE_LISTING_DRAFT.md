# SIGNAL // BREACH — черновик карточки RuStore v1

**Статус:** тексты для утверждения перед заведением карточки. Не загружено в RuStore. Все скриншоты должны быть сняты с финального Android release APK.

## Название

**SIGNAL // BREACH**

В UI проекта написание с пробелами вокруг `//`; проверить, допускает ли RuStore это имя как отображаемое и уникально ли оно.

## Короткое описание

Атмосферный киберпанк-сапёр с сюжетной кампанией и свободной игрой. Полностью офлайн.

## Полное описание

**SIGNAL // BREACH** — атмосферная головоломка по правилам классического «Сапёра» в мире повреждённой сети ретрансляторов.

Восстанавливайте узлы, отслеживайте заражения и постепенно раскрывайте историю загадочного сигнала. В сюжетном режиме вас ждут 10 операций с брифингами и растущей сложностью. Хотите сыграть без сюжета? Выбирайте свободный режим с тремя уровнями плотности поля: TRACE, BREACH и BLACK ICE.

**Что есть в игре**
- Классическая логика «Сапёра» с числами, минами и отмеченными клетками.
- Десять сюжетных операций и отдельный Free Run.
- Два вида обозначений: розовая отметка найденной мины в режиме «Скан» и оранжевая временная гипотеза в режиме «Карантин».
- Локальное сохранение пройденных операций и возможность продолжить незавершённую партию.
- Интерфейс на русском и английском языках.
- Работа без интернета, рекламы, регистрации и встроенных покупок.

Это классический «Сапёр»: отдельные игровые ситуации могут требовать выбора между несколькими вариантами. Игра не обещает, что каждое поле можно решить без угадывания.

## Какие скриншоты делать

1. Главный экран с `SIGNAL // BREACH` и двумя режимами.
2. Сетка 10 операций Campaign — виден прогресс и стилистика.
3. Открытая миссия с розовыми и оранжевыми отметками одновременно.
4. Free Run (включая большое поле), чтобы показать альтернативу кампании.
5. Экран победы / итог и «Поделиться результатом».

Никаких нарисованных фальшивых UI-скриншотов вместо реального геймплея. Проверить читаемость на мобильных ширинах. Параметры изображения и обязательные поля **проверить в действующей консоли** перед загрузкой.
