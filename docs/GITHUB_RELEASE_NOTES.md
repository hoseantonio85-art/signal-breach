# SIGNAL//BREACH v0.2.11 — Android test

Исправлено отображение помеченных мин в зависимости от выбранного режима:

- **Скан** — розовые метки, как до v0.2.10.
- **Карантин** — янтарные метки.
- **Разбор поля** — обнаруженные мины остаются красными прицелами.
- Уже поставленные метки перекрашиваются при переключении. Правила, минные поля и сохранения не менялись.
- Добавлены автоматические проверки обоих режимов.

Сохранились все возможности предыдущих версий: сглаженный баланс OP 07–10, автосохранение и Continue, Android офлайн, обновления без удаления.

### Установка
Скачайте `signal-breach-0.2.11-android-debug.apk` и установите **поверх v0.2.10 без удаления**, чтобы сохранить прогресс. APK подписан тем же стабильным тестовым сертификатом. Это GitHub pre-release, **не** production RuStore.
