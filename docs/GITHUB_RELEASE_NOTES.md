# SIGNAL//BREACH v0.2.12 — разные метки для «Скана» и «Карантина»

**Исправлена сама причина ошибки предыдущей версии.** Теперь цвет определяется тем, как была поставлена метка, и остаётся с ней, а не меняется при переключении режима.

- **СКАН:** длинное нажатие на клетку (на ПК — правая кнопка мыши) ставит **розовую метку** найденной мины.
- **КАРАНТИН:** обычное нажатие ставит **оранжевую временную гипотезу** о мине.
- Розовые и оранжевые отметки могут находиться на одном поле одновременно и сохраняют свои цвета при переключении.
- Повторная отметка того же вида снимает её; отметка другим видом меняет цвет и тип клетки.
- Ранее установленные метки из v0.2.11 сохраняются и считаются розовыми, а новые оранжевые гипотезы и розовые отметки сохраняются между сеансами.
- Настоящие мины при разборе поля остаются красными прицелами.

Это изменение **представления и сохранения типа отметки**, а не перерасчёт мин. Пока оба типа занимают одну метку в счётчике и учитываются при открытии соседей (chord), как и раньше. Сложность миссий и общий прогресс не меняются.
