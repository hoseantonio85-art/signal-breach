# SIGNAL//BREACH v0.2.10 — тестовый Android-выпуск

Это **предварительная версия для тестирования**, а не релиз RuStore. APK подписан постоянным тестовым ключом.

### Что нового

- Android-версия на Capacitor с офлайн-работой, автосохранением миссий и продолжением партии после закрытия.
- Обновления APK поверх предыдущих с сохранением прогресса.
- Сглажена сложность сюжетных операций OP 07–10: 40 / 47 / 54 / 62 мины.
- Первый ход в Campaign защищает область 3×3, включая края и углы. Free Run не менялся.
- Предположительные карантинные отметки теперь янтарные, подтверждённые мины — красные прицелы.
- Исправлена отправка результата в другие приложения.
- Убран резервный код с главного экрана; автосохранение осталось.
- Улучшены оформление, шрифты, иконки и звук.

### Установка

Скачайте APK из Assets этого выпуска, откройте на Android и установите. **На предыдущие тестовые версии v0.2.5 и выше устанавливайте поверх, не удаляя приложение** — тогда прогресс сохраняется. Старые версии до v0.2.5 могли быть подписаны несовместимым временным сертификатом.

### Известные задачи

Продолжаем тестировать поздние операции, громкость на телефоне и удобство новых карантинных меток. RuStore будет подготовлен отдельно.
