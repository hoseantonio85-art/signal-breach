## ПРАВИЛЬНАЯ UX-семантика двух видов меток — v0.2.12 (2026-11-05)
- **Важное уточнение пользователя:** ранние 0.2.10 и 0.2.11 реализовали задачу неправильно: цвет переключался вместе с режимом игры. В действительности метка должна **запоминать источник**: `СКАН` (розовая, более уверенная) и `КАРАНТИН` (оранжевая, временная гипотеза). Оба вида должны одновременно стоять на карте и сохранять свой цвет после переключения. Не возвращаться к зависимости цветового оформления от текущего активного режима!
- Добавлено необязательное поле `Cell.markOrigin?: 'scan' | 'quarantine'` при существующем `quarantined: boolean`. Отсутствующий `markOrigin` на старом флаге из v0.2.11 означает **розовую отметку сканирования**, так что старые сохранения/OP 09 не теряются. При создании новой отметки тип берётся из активного режима. В Скане длинное нажатие или правая кнопка мыши ставит розовую; в Карантине обычный тап — оранжевую; повторное однотипное действие снимает метку, другой тип конвертирует её. `flagged-tentative` — CSS только по полю клетки, без перекраски при смене режима. Актуальные подтверждённые мины после поражения остаются красными.
- **ВАЖНО по правилам:** текущий `quarantined` остаётся единым логическим флагом обоих видов: оба учитываются в показателе оставшихся мин и в chord, как и раньше. Никакой невидимой смены игрового баланса. Если пользователь захочет, можно позже отделить временные гипотезы и от логики chord/счётчика — но только после отдельного решения.
- Новая версия `0.2.12` / `versionCode 2012`, тот же постоянный тестовый сертификат. Регрессионные тесты проверяют розовые и оранжевые отметки одновременно, переключения, устаревшие сохранения, корректность ввода, красные прицелы. Пользователь ранее разрешил мёрдж исправлений сразу после зелёного CI.
- После публикации через `main` GitHub Pages и GitHub Pre-release проверить на телефоне сохранность OP 09 и два вида меток. [Issue #17](https://github.com/hoseantonio85-art/signal-breach/issues/17) открыта до проверки.

Не считать это гарантией восстановления: возможен Android Auto Backup. Требуется устойчивый путь обновления с одной подписью (issue #7).
- UI-замечание: галочка CircleCheck у завершённой миссии на Android казалась опущенной. В PR #4 позиция теперь абсолютная, с **равным отступом сверху и справа**: 18px обычный размер, 12px при ширине до 390px. Нужна визуальная проверка после обновления.
- Номер сборки больше не hardcoded в RU/EN: **`package.json` v0.2.1** — единый источник версии для WEB/ANDROID надписи и native Android versionName/versionCode (2001). Для каждого следующего релиза обновлять package.json. APK с этим изменением требует нового QA, старую установку с ценным прогрессом не удалять только ради номера версии.
