## Что это за проект
- Атмосферный synthwave/cyberpunk-сапёр SIGNAL//BREACH: 10 сюжетных операций, 3 режима Free Run, языки RU/EN, звук и адаптивная веб-версия.
- Стек: React 19, TypeScript, Vite, Lucide, собственный игровой движок `src/game/engine.ts`.
- Цель следующего этапа — **первый полностью офлайн debug APK для Android**, затем надёжное сохранение/пауза/Back, QA, подготовка бесплатного релиза в RuStore. Без рекламы, серверов, аккаунтов и покупок.

## Обновление 2026-11-01: Android QA, выравнивание галочки и версия
- Пользователь установил новую APK с фирменной launcher-иконкой, **подтвердил работу без интернета и сохранение прогресса кампании**. Обновление поверх прежнего APK не удалось, пришлось удалить и установить заново; прогресс при этом сохранился **на одном тестовом телефоне**. Не считать это гарантией восстановления: возможен Android Auto Backup. Требуется устойчивый путь обновления с одной подписью (issue #7).
- UI-замечание: галочка CircleCheck у завершённой миссии на Android казалась опущенной. В PR #4 позиция теперь абсолютная, с **равным отступом сверху и справа**: 18px обычный размер, 12px при ширине до 390px. Нужна визуальная проверка после обновления.
- Номер сборки больше не hardcoded в RU/EN: **`package.json` v0.2.1** — единый источник версии для WEB/ANDROID надписи и native Android versionName/versionCode (2001). Для каждого следующего релиза обновлять package.json. APK с этим изменением требует нового QA, старую установку с ценным прогрессом не удалять только ради номера версии.
