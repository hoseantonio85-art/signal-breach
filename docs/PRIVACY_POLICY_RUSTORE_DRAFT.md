# SIGNAL // BREACH — черновик уведомления о конфиденциальности

**Версия черновика: 2026-11-12. Не публиковать как утверждённую юридическую политику без финальной проверки APK, заполнения реквизитов разработчика и согласования.**

## Что делает приложение

SIGNAL // BREACH — офлайн-игра для Android. Она не требует регистрации, аккаунта или подключения к интернету для игры. По проверенному исходному коду версии 0.2.12 в приложении нет встроенной рекламы, аналитических счётчиков, телеметрии или игрового сервера.

## Данные на устройстве

Игра хранит локально в памяти приложения на устройстве игровой прогресс, лучшие результаты, разблокированные операции, текущую незавершённую партию и выбранный язык. Эти данные нужны для продолжения игры и не загружаются разработчику через функции игры. Данные остаются на устройстве, пока пользователь не удалит их средствами Android (например, через очистку хранилища приложения) либо пока их не удалит система в соответствии со своими настройками.

При удалении приложения локальные сохранения могут быть потеряны. При повторной установке перенос прогресса не гарантируется.

## Отправка результата

Кнопка «Поделиться результатом» работает только по действию пользователя. Она передаёт подготовленный текст с результатом в системное меню «Поделиться» Android; пользователь сам выбирает, какому приложению его отправить. После этого дальнейшая обработка текста регулируется условиями выбранного приложения. Игра не отправляет результаты сама по себе.

## Интернет и разрешения

В собранном тестовом Android APK имеется системное разрешение `android.permission.INTERNET`, унаследованное от Android/Capacitor. Это разрешение **само по себе не означает отправку данных**. В игровом коде нет функции передачи прогресса на сервер. Перед публикацией необходимо отдельно подтвердить отсутствие неожиданных сетевых обращений у **финальной подписанной production APK** и проверить все SDK/разрешения.
