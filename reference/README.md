# Prototype reference

The standalone HTML prototype built in chat remains the visual/UX baseline while the application is migrated to TypeScript.

Migration must preserve these established behaviors:

- synthwave/cyberpunk visual language
- boot screen before the main menu
- Campaign and Free Run entry points
- RU/EN localization
- first-click-safe Minesweeper rules
- mobile SCAN / QUARANTINE controls plus long press
- campaign briefings from Col. Mira Voss
- frozen post-loss map review with visible mines
- local progress and score persistence

A frozen HTML snapshot will be stored here once the TypeScript shell and deploy pipeline are verified.
